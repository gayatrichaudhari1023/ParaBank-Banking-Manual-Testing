# ParaBank Online Banking Application Testing

## 📌 Project Overview
This project focuses on the end-to-end Functional Manual Testing and Backend API Verification of the ParaBank Online Banking system. It covers critical security flows like registration validation, fund transfer limitations, and Postman API responses.

## 🛠️ Tools & Technologies Used
* **Documentation:** Microsoft Excel
* **API Testing Tool:** Postman (Basics)
* **Testing Concepts:** Functional Testing, Negative Testing, Test Case Specification (STLC)

## 🗂️ Modules Tested
1. **Fund Transfer:** Validated successful transfers between accounts and insufficient balance error handling.
2. **User Registration:** Tested field mismatch rules (Password vs Confirm Password).
3. **User Login:** Verified system security using valid usernames with incorrect passwords.
4. **API Testing:** Executed GET requests in Postman to fetch account details, validating Status Code 200 OK.

## 📄 Deliverables Attached
* **ParaBank_Banking_Manual_Testing_Project.xlsx:** Detailed manual test cases with Test ID, Steps, and Expected Results.
